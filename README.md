# 《橋頭糖廠命案：死神鐮刀的復仇》

作者：SY

橋頭糖廠的廢棄倉庫裡，前廠長倒在血泊中，身旁躺著一把鐮刀。新人女刑警跟著老刑警接手此案，目擊者卻說，那晚有個人影拖著東西走進舊鐵軌後的草叢——老一輩口中的「草刈仔鬼」。太過平靜的遺孀、各懷心事的兒女，還有塵封二十年的舊案，正把這名新人女刑警一步步拉進糖廠深處。全十二章免費公開。
