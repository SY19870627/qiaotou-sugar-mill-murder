# 《橋頭糖廠命案：死神鐮刀的復仇》

作者：SY

橋頭糖廠的廢棄倉庫裡，退休的前廠長田南堂倒在血泊中，身旁躺著一把鐮刀。新人女刑警石懷鈺跟著老刑警余添富接手此案，目擊者卻說，那晚有個拖著東西的人影慢慢走進舊鐵軌後的草叢——老一輩口中的「草刈仔鬼」。太過平靜的遺孀、各懷心事的兒女，還有一樁塵封二十年的舊案，正把她一步步拉進糖廠深處。
